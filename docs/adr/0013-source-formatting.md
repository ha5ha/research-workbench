# ADR-0013：统一源代码格式

- 状态：Accepted（2026-11-11，1.0 编码规范与可维护性要求）

长行 JSX 和压缩的服务代码降低审阅质量。选用一个开发期格式工具，不增加产品运行时或视觉系统。

| 候选 | 许可/维护/依赖 | 决定 |
| --- | --- | --- |
| [Prettier](https://github.com/prettier/prettier) 3.9.10 | MIT；官方持续发布；包含解析器，不新增生产依赖 | 采用固定版，只启用常规 CLI；覆盖 TS/TSX/CSS/JSON/Markdown |
| [Biome](https://github.com/biomejs/biome) | MIT/Apache-2.0；持续维护；平台二进制，兼有 lint/格式 | 暂不采用；已有类型/边界 lint，无需引入第二套检查配置或二进制 |

复用 Prettier 默认语法规则，保留仓库的无尾逗号风格。只格式化本轮改动的源文件，不为统一样式改动无关文件。脚本提供显式文件参数，CI 对差异文件检查；不把未格式化历史文件伪装为已通过。新增依赖固定在开发清单，不随应用分发。删除工具即可退出，语义和数据不受影响。

验证：格式检查、类型、边界 lint、相关测试及实际 UI 回归。升级时固定版本、检查格式差异后再采用。
