# ADR-0020：统一 OpenResearch 风格的基础控件

- 状态：Accepted
- 日期：2026-11-11
- 授权：所有者指出组件粗糙、下拉箭头不合理，要求整体规范并向 OpenResearch 靠齐；沿用直接重构与开源代码复用授权
- 关联：ADR-0009/0019、原型 UI 合同

## 问题与边界

聊天头部将静态 tag 样式用于按钮，字符箭头依赖字体基线；模型入口带下拉箭头却打开整个设置页。导航、输入区和设置分别实现图标、尺寸、按钮与菜单状态。继续局部覆盖会增加重复样式。

本轮统一现有交互的视觉和基本键盘行为，减少配置与查看科研记录时的识别成本。布局、品牌、字体下限、Core/审批/数据边界保持原合同。没有新业务页面，不改变工具权限或研究对象状态。

## 实施

1. `packages/ui` 成为真正的共享展示包，仅依赖现有 React 19.3.1 peer，开发类型使用已安装的 19.3.0。适配 Button/IconButton/MenuItem，统一 DropdownTrigger/Popover 与 SVG Icon；无 RPC 或持久化业务状态。
2. 共享 token 管尺寸、间距、边框、焦点与短过渡。默认操作至少 32px，窄屏主要操作至少 40px；SVG 24px 画布、16px 常用显示、14px 下拉指示、2px 描边、圆头。文字不低于 12px。
3. 历史、模型、权限、项目入口使用同一控件语法；模型头部与输入区复用同一个模型菜单。按钮默认中性，真实状态另作文本标识，配置存在不再用绿色胶囊冒充成功状态。
4. 清除公共按钮和菜单的重复外观规则，页面 CSS 只保留布局和内容角色；跨页替换字符图标。设置中的通用 Segmented/ComboBox/Switch 迁入共享包，替换旧出口。
5. Popover 处理外围点击、Esc、焦点返回；菜单支持箭头/Home/End。权限面板保留 radiogroup 语义，不伪装纯动作菜单；操作仍调用原 Core 白名单。

## 验证与退出

真实 Electron 覆盖默认、hover、展开、选择、禁用、加载、空态、错误、键盘、长模型名、窄屏和 200% 整窗截图；1440×900、1024×768、390×844 无横向溢出、字号达标。最终连续三轮每轮 25 项控件、21 项聊天交互、科研闭环及 6 项视图检查通过，构建/记录源码哈希与当前文件一致。保留修改前截图；一轮独立存量视觉评审、一次轻量 UX 走查已完成，修正后由主代理复验。[完整证据与限制](../../design/implementation/shared-controls-20261111/README.md)。

类型检查、架构 lint、相关交互/许可检查通过。全量测试沙箱内 168 通过、3 项 Windows taskkill/EBUSY 失败、1 跳过；相关三文件正常用户重跑 14 项全通过。许可收集 142 个精确第三方包与 Electron，145 个输出哈希核对。构建仅为生成真实桌面验证产物；原 1.0 便携包未重打。完整版权、版本/文件来源、组件规范和截图基线同步更新。

UX 发现的查看运行定位、确认按钮措辞与哈希标签已修正；原始产物内容预览需要受限 Core 接口，记录到路线 N09，不包含在本轮已完成范围。

升级只更换 registry/共享展示组件并重跑交互与视觉验证；科研数据、运行台账和权限服务不随展示层回退。旧单页控件不保留为第二套实现。
