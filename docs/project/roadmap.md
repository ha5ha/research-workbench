## 后续优先顺序

以下均待认领；认领后补分支/变更、负责人和证据。先做开源评估与小 fixture，避免通过增加页面弥补工作流不足。

| ID / 优先级 | 减少的研究负担 / 范围                                     | 验收要求                                                                                                |
| ----------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| N01 / 高    | baseline/repro/stats Skills，减少复现、对照与统计手工操作 | 开源候选与许可 ADR；脚本复算；输入、产物、审批、来源和评测；小型真实 ML/算法样板                        |
| N02 / 高    | 证据更正与撤销，避免错误结论继续被使用                    | 保留原版及理由，引用显示更正状态；检查点/新会话不升级旧结论；并发与重开回归                             |
| N03 / 高    | 可搬运复现包，减少搬机器重新找环境/数据                   | manifest/代码/分析/环境身份、缺件显式；干净环境重放并核对哈希；数据许可与秘密排除                       |
| N04 / 高    | 磁盘保留与安全清理，控制长时日志和产物成本                | 引用分析、预览、人工批准、恢复；原始证据不自动删；活动/unknown Job 不清理                               |
| N05 / 中    | 更复杂 SSH 作业与长期计算                                 | 网络中断、增量日志、真实长时任务；同 Job 恢复和预算约束；先独立场景评测                                 |
| N06 / 中    | 跨日方向恢复与易用性评测                                  | 固定任务、模型/预算、工具版本；研究者找问题/来源/下一步的时间与手工步骤；与 OpenResearch 建立同任务对照 |
| N07 / 中    | 可维护存储与协议                                          | 先测纯状态规则再迁包；备份/版本冲突/迁移中断恢复；一个权威写入源，删除旧路径                            |
| N08 / 中    | 公开分发加固                                              | 在现有三平台 CI 基础上补干净 Windows、签名/更新与版本迁移；所有者安排安全报告渠道                       |

本轮独立 UX 新增 N09：

| ID / 优先级 | 减少的研究负担 / 范围                                           | 验收要求                                                                                                                                      |
| ----------- | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| N09 / 高    | 从运行产物/结论来源直接查看已归档原始内容，减少核对数值时找文件 | Core 受限读接口，核对运行身份/哈希/大小与媒体类型；文本/表格预览和下载；损坏/缺件/大文件/拒绝路径、三尺寸、确认前回查；不直接暴露任意文件读取 |

问题来自[界面与交互验证](validation.md#ui)。本轮已修正查看运行的定位、立即确认的按钮措辞及哈希标签；原始内容预览需要新增受限数据接口，未作为基础控件润色交付。

“比 OpenResearch 更好”是产品目标，当前没有对照结果。比较时同时记录手工步骤、配置时间、找结果时间、错误次数、来源可追溯率与故障恢复；不以面板数量或对象数量证明优势。
