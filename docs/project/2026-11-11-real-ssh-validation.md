## 输入与计算边界

- 输入来自已接受任务 T011 的 CASE_OUTCOMES、METRICS_BY_SOURCE、SUMMARY_BY_BACKBONE 三份 CSV。复制前逐份对照原项目 EVIDENCE_INDEX 的 SHA-256，未用人工填写的数值代替计算。
- 2016 行 = 6 个源模型 × 每源 336 个 video/study。先逐源复核，再分别汇总两个主干的三个源种子；不跨主干平均排名，不声称患者级独立或新科学重复。
- 用独立 Python 标准库脚本重算 MAE、相对源模型变化、恶化率、平均正伤害、平均收益、最坏 17 项正伤害，并核对源均值与样本 SD。
- 120 项数值检查通过，最大绝对差 `1.7763568394002505e-15`；本机与远端逐源结果一致。两次远端复核的主指标差值为 0。这证明保存记录的算术可重复，不证明方法泛化或机制成立。
- 本机 Python 3.12.10，服务器系统 Python 3.8.10，选定研究环境 Python 3.9.25。两边运行同一冻结脚本、同一哈希输入，未安装软件。

## 实测促成的修复

1. **seed 顺序误拒收**：改为按 seed 身份一一匹配，计算时按冻结协议顺序归一；重复、缺失、null、空字符串和陌生 seed 仍拒绝。没有把旧失败记录改成成功，以新 attempt 复验。
2. **远端目录固定在 home**：计划增加可选绝对 Job 根目录和 Python 路径，进入冻结摘要与可比身份；UI 在批准前显示。逐级拒绝目录链接，上传后核验文件 SHA-256。
3. **凭据与执行分离**：同一个 SshExecutor/bootstrap/supervisor 允许 Core 构造时注入受信任传输，RPC/模型不能指定本地凭据程序。本轮复用项目既有加密凭据代理；没有把 Paramiko 或凭据复制进客户端。
