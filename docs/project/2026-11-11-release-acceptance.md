# 1.0.0 本地交付验收

2026-11-11。有限范围的计算科研 Agent 1.0.0 已通过本机验收，生成 Windows x64 便携包。生产 Core/Main/preload 在最后一轮模型、本地恢复和分发验证期间保持相同哈希。本轮没有提交、推送或公开发布。

## 交付行为

默认是项目导航与大对话，细节按需打开。用户描述目标，Agent 起草任务书和冻结计划，研究者核对范围与冻结代码后一次批准；随后查看运行、产物、带来源候选结论与下一步决策。旧手工运行表单、重复确认、旧 runtime 双接口已删除，没有保留旧模式兼容入口。

科研工具、schema、提示与权限由 Core 持有，pi 只适配通用会话和工具。文件工具/Skill 共用实际路径策略与无内部 token 的状态投影；实验归档由 Core 从精确成功 Run 重核并派生结果。Windows 使用一个独立后台启动边界，确认丢失保留 unknown，重开核对原 Job。决策分别见 ADR-0009/0015/0017/0018。

## 使用与恢复

打开项目，在设置中配置模型、Git 和所需的 SSH；本地兼容端点可无 key。运行先审阅固定版本，修改方案生成新版本，撤回/替代的方案不能再批准。完整使用、开发与打包命令见根 README。

更新或回滚前先核对活动/unknown Job，退出 Core，备份工作区 `.research` 和加密用户配置，并检查存储版本。遇到 unknown 先核对同一 Job，不新提交冒充恢复；旧应用不写未知 schema。测试留下的历史失败和未知记录保留，不清理用户原始科研证据。

## 范围边界与后续

当前验证是确定性函数与真实归档预测的维护重算，不证明科学泛化、长期GPU任务、复杂SSH认证或竞品优势。Core不是OS沙箱。便携包未签名、使用默认Electron图标，远端CI和干净机器尚待独立验收。

专业统计/复现Skills、证据更正链、完整复现包与磁盘保留优先，其他后置能力见[路线](roadmap.md)。架构、已实现/待建设能力与贡献入口从[项目控制台](README.md)进入；历史方案不再作为当前完成度清单。
