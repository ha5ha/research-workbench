真实模型最终验收保留一次错误参数的安全拒绝：必填 hypothesis 被拼成 hypotheses，SDK 在执行前拒绝；模型同回合纠正后成功，只有三实验/三 Run，无额外副作用。未恢复的工具错误为零。没有把拒绝删除或宣称零工具错误；[验证说明](validation.md#research-loop)记录范围，逐调用审计保留本机。

QA 驱动在人工侧 UI 操作批准、确认和决策；模型只提出方案和候选结论。这不是真人可用性研究，也没有同任务竞品对照，不能据此宣称超越 OpenResearch。

## 保留的限制

- Core 权限/工作区约束和审批不是 OS 沙箱；批准普通 Shell 或研究脚本仍需核对代码。
- 当前只验证确定性数值夹具和真实归档预测维护重算，不证明科学泛化、真实训练效果或长期 GPU 运行。
- JSON/CSV 指标契约与产物有配额；复杂 SSH 认证、真实 TCP 断线、任意机器环境未验收。
- 新路径不产生含内部 token 的检查点；早期预览生成的旧文件不自动清理，保留原始审计材料。
- 便携包未签名，默认 Electron 图标；远端 CI、干净机器、自动更新和跨平台分发后置。

专业统计/复现 Skills、证据更正链、完整复现包、磁盘保留，以及完整 IDE、PTY/Python LSP、Anthropic、多 Agent、论文生成、云平台和应用内团队协作见[后续路线](roadmap.md)。

每个通过项绑定实际记录和构建身份；历史失败、unknown 和负结果保留，不改写为成功。
