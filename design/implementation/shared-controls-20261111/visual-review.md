## 按影响排序的问题

### 1. 设置页保留了合同已否决的独立协议卡

**位置与证据：** `controls/settings-1440.png` 的模型协议区同时出现 OpenAI 兼容、DeepSeek 原生、Anthropic 三张卡；`settings-390.png` 也可见 DeepSeek 原生卡。合同 6.1 明确“模型只列 OpenAI 协议与 Anthropic 占位，不再单独列 DeepSeek Provider”。这里指协议卡，不是模型列表中的 deepseek 模型名称。

**影响：** 同一设置区仍有旧结构，移动端额外占一块纵向空间，也给出与合同不同的协议选择。其优先级高于箭头和圆角等细节。它可能是已有实现遗留，应单独确认本轮处理范围，不能把当前截图记录为完全符合 UI 合同。

**修正目标：** 按合同保留两类协议卡，保持目前卡片字体、间距与边框；删除第三种协议所占空间，不补充新的说明卡。

**验收：** 1440px 和 390px 模型设置中不再出现独立 DeepSeek Provider 卡；OpenAI 兼容列表仍可正常展示其模型名称。若确实已有后续授权，则应先更新这条合同，不以截图推定授权。

### 2. 对话底部重复元数据削弱了输入区的收尾

**位置与证据：** `controls/default-1440.png` 底部出现“gpt-4o-mini · OpenAI 兼容 真实模型会话”，而模型已经同时出现在会话顶部和输入工具栏。`chat-390.png`、`model-390.png`、`permission-390.png` 中完整长模型名又在输入框下方占两行；`controls-200pct.png` 中同一串文字仍横跨输入区底部。

**影响：** 重复的非操作文字挤占窄屏与放大后的纵向空间，且“真实模型会话”属于实现状态说明，不能帮助研究者判断下一步。长模型名在控件内已经合理省略，底部又展开，形成不一致的密度。

**修正目标：** 删除输入区下方重复的模型 / 协议 / “真实模型会话”脚注。保留现有可点击模型入口和菜单内的完整名称，不删除必要的当前模型信息。

**验收：** 390px 与 200% 时，输入框下方不再出现重复的两行模型文字；模型仍可从工具栏识别和切换。删减后保持输入区与窗口底边的现有安全间距，不放大欢迎区或补入其他文案。

### 3. 欢迎区操作高度尚未完全纳入本轮尺寸规则

**位置与证据：** `controls/default-1440.png` 中“梳理当前项目 / 准备一个实验”两个矩形操作约为 42px 高；同页工具栏操作及 `research/compass-1440.png` 的导出、编辑、讨论等操作约为 32px。本轮交接拟定的默认操作高度为 32px，≤900px 为 40px。

**影响：** 此处不是裁切或可用性缺陷，但在“统一当前页控件”的任务中留下了一个未说明的尺寸例外，容易让下一批界面继续各自决定按钮高度。

**修正目标：** 若它们属于普通操作，采用桌面 32px / 窄屏 40px 的共同规格；若它们属于建议卡片，则把例外及其尺寸写入控件规范，保留现有内容与布局，不增加另一套视觉样式。

**验收：** 桌面欢迎区操作与最终成文规范一致；390px 下仍为清晰、可触控的操作。不要为追求统一把移动操作降至 32px。

## 已成立的部分

- 用户原图中使用字符拼出的微小下拉符号已被统一的描边 chevron 取代；历史、模型、权限入口的图标和箭头有明确分工。模型展开后箭头朝向也有变化。
- `model-open-1440.png` 将当前模型的勾选与键盘焦点描边分开；`chat-1024.png` 和 `permission-390.png` 也能看见明确的焦点或选中边框。不要因追求更淡的样式删掉这些反馈。
- 当前 390px 截图中的模型名使用省略号，输入工具栏自然换成两行；模型菜单、权限面板与冻结文件预览没有可见的横向溢出。完整代码在预览内部换行，没有靠缩小文字解决窄屏。
- 科研页操作、代码工作面工具栏、对话菜单已经共享中性表面、细边框和紧凑图标语言，未看到需要另起视觉系统的理由。
- `compass-390.png` 的“当前方向—实验与运行—运行详情”仍能读出层级；现有两层容器承担不同信息，不建议为减少边框而合并。

## 静态截图的验证边界

没有录屏或可操作页面，因此没有验证 120ms 动效、reduced-motion、菜单键盘路径、Esc、焦点返回、真实点击目标尺寸或保存行为。截图中看到焦点，不等于整条键盘路径通过。没有从截图判断 CSS 是否实际引用 token，也没有据此声明精确对比度或所有字号自动检查通过。

设置组合框中，当前字段为自定义长模型名，列表有灰底候选项；单凭截图不能判断灰底是 hover、键盘活动项还是当前选择，因此本次不将其误报为选中错误，建议功能验证时核对。

保留：统一的 SVG 箭头 / 图标与可见焦点；中性紧凑菜单、移动工具栏换行及科研内容的现有阅读层级。
