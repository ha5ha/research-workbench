自选任务：从“准备一个实验”发起一个 baseline 实验，审阅方案并尝试取得可观察的本地运行结果。

完成程度：**部分完成，被测试环境状态变化中断**。已经从真实 UI 发送请求并取得冻结方案入口；尚未完成审阅或运行。测试使用本地确定性样板，不能据此验收真实模型或科学有效性。
