## OpenResearch UI adaptation

Source: https://github.com/alphaXiv/OpenResearch

Revision: `92d6423a14b02cc6de85d3e2383dce6cb4dcb7fd`

Research Workbench adapts neutral light-theme values from `ui/src/theme.css` and the review-strip layout/interaction from `ui/src/components/PlanStrip.tsx`. It also directly adapts the bottom-following refs, scroll handler, resize observation, and IME Enter guard from `ui/src/components/ChatPanel.tsx` into `apps/desktop/src/renderer/src/views/ChatView.tsx` (ADR-0019). The scroll target uses the existing DOM instead of the upstream virtualizer; upstream API, state, runtime, and component dependencies are not included. Product names and logos are not reused.

ADR-0020 also adapts `ui/src/components/ui/{Button,IconButton,MenuItem}.tsx` and `ui/src/components/ModelPicker.tsx` (pill/menu styles and outside-pointer lifecycle) into `packages/ui/src/{primitives,Popover}.tsx` and `components.css`. Tailwind declarations are translated to the existing shared CSS tokens; keyboard, focus, editable fields and viewport positioning are local adaptations. The model/permission API and state remain Research Workbench's own. Lucide icon source data is separately attributed below and in `packages/ui/vendor/lucide/`.
